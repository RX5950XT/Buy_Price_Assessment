# Lessons

- 子代理若因額度或暫時性資源限制中止，在使用者允許恢復後應立即重派；主線同時持續可獨立完成的工作，不把子代理失敗當成整體 blocker。
- 時間序列的「月進度」不可用事後實際交易日總數；應只使用當下可知的日曆資訊，並以截斷資料不改變既有特徵的回歸測試防止前視。
- ETF 分割不只要還原價格，成交量、融資融券與流通單位也必須轉成可比基準，避免模型學到機械 regime shift。
- 外部 API 類別不可用模糊字串包含判定；採 exact allowlist 且未知值 fail-closed，才能及早發現 schema 漂移。
- 時序模型快取必須包含特徵值與設定指紋；只比日期會在特徵邏輯變更後誤用舊預測。
- **字典提取防禦性編碼**：在模組邊界或報告渲染器提取字典（例如 `results` / `holdout` 等多層嵌套字典）的值時，應使用 `.get()` 方法並給予安全的預設值。避免在單元測試或特定環境下因為傳入 Mock 假資料缺少部分欄位而引發 KeyError 中斷。
- **閉包函式綁定迴圈變數 (B023)**：在 `for` 迴圈內部定義輔助函式並引用迴圈變數（如 `key` 或 `values`）時，會引發靜態檢查（Ruff B023）警告。應利用預設參數的形式（如 `def get_val(c, key=key, values=values)`）將迴圈變數顯式綁定到該函式的作用域中。
- **完整月份截止以資料末日為準**：`run_analysis` 不可用 `date.today()` 推算 `complete_through`。資料若停在月中，用今天會把不完整月標成完整月，讓 walk-forward 快取失效並重訓。應取 `last_complete_month(資料末日)`。
- **中止中的重訓會弄髒快取**：`walk_forward_{feature_set}.csv` 在訓練過程就會被覆寫。被 kill 的 analyze 若已寫入半成品，立刻 `git checkout --` 還原，不要讓後續測試在髒快取上重訓。
- **決策規則拆解不可掃參**：門檻與截止日必須預先指定並全部入表。第 5 日截止只能來自第一版已公布的 oracle 前 5 日占比，不能從樣本外挑「最好的截止日」。
- **美股 as-of 是 T-1 不是 T**：美股日 T 的收盤落在臺灣 T+1 凌晨，臺灣 T 日 09:00 只能用美股日期 `<= T-1`。同一曆日美股絕對不可進當日開盤規則。領先特徵對齊後不可再 `shift(1)`。
- **高頻訊號加短截止 ≈ 延後買入**：TSM 日報酬 < 0 約一半交易日為真，配第 5 日截止時平均買入日約 2，只是把第 1 日延後，不是過濾。
- **截止日必須限制搜尋窗口**：`select_first_true_or_deadline` 若對整月找第一個 True，稀有訊號會買到第 6 日之後，強制率被低估。應只在 `trading_day <= cutoff` 內搜尋，否則於窗口末日強制買入。
- **失敗機制修正不可掃參**：過密改預先指定的經濟整數（1%）或改成第 1 日除非不利；過稀改單日暫緩、不拉長連升。沒贏第 1 日就照實寫，不改門檻重跑。
- **匯率方向必須與訊號同向**：`usd_twd_up` 是美元／新臺幣上升，即臺幣貶值。表頭寫「臺幣升值暫緩」會與回測相反。
- **領先規則測試不可在缺資料時整段跳過**：沒接到 `lead_rules` 應 fail，不能讓整合測試在沒有外部檔時仍綠。分析本身缺 `tsm_us.csv`／`sox_us.csv`／`usd_twd.csv` 也必須 raise，不可寫出沒有領先規則的成功報告。
- **複製實驗的截止日理由不可改寫**：第 5 日截止是 0050 已公布的 48.2%，VT 即使前 5 日占比是 43.3% 也不得改成從 VT 樣本重估。
- **同一市場的 T-1 不是隔夜領先**：TSM／SOX 與 VT 同時段交易，T-1 只是前一美股日；文件必須寫明，避免當成 0050 那種跨市場隔夜。
- **點估計小幅領先不是贏**：VT 的 SOX 規則 +6 bps、僅機率 +5 bps，CI 跨 0 就不得宣稱優於第 1 日。
