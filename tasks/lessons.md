# Lessons

- 子代理若因額度或暫時性資源限制中止，在使用者允許恢復後應立即重派；主線同時持續可獨立完成的工作，不把子代理失敗當成整體 blocker。
- 時間序列的「月進度」不可用事後實際交易日總數；應只使用當下可知的日曆資訊，並以截斷資料不改變既有特徵的回歸測試防止前視。
- ETF 分割不只要還原價格，成交量、融資融券與流通單位也必須轉成可比基準，避免模型學到機械 regime shift。
- 外部 API 類別不可用模糊字串包含判定；採 exact allowlist 且未知值 fail-closed，才能及早發現 schema 漂移。
- 時序模型快取必須包含特徵值與設定指紋；只比日期會在特徵邏輯變更後誤用舊預測。
- **字典提取防禦性編碼**：在模組邊界或報告渲染器提取字典（例如 `results` / `holdout` 等多層嵌套字典）的值時，應使用 `.get()` 方法並給予安全的預設值。避免在單元測試或特定環境下因為傳入 Mock 假資料缺少部分欄位而引發 KeyError 中斷。
- **閉包函式綁定迴圈變數 (B023)**：在 `for` 迴圈內部定義輔助函式並引用迴圈變數（如 `key` 或 `values`）時，會引發靜態檢查（Ruff B023）警告。應利用預設參數的形式（如 `def get_val(c, key=key, values=values)`）將迴圈變數顯式綁定到該函式的作用域中。
